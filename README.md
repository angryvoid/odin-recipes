# odin-recipes

A introductory project for The Odin Project that focuses just on the foundations of HTML. 

The project was to make a simple recipe site.

Includes a Home Page and (3) Recipe Pages, with recipes taken from allrecipes.com,
and images taken from Unsplash (with credits in the captions).

Overall relatively simple of a project -- main points that made me
scratch my head for a moment were to properly format the image sizes
as well as using the figure/figcaption element and tag so that
I could properly credit the owners/photographers of the free
images I used.
